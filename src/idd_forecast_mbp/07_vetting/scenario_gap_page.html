What differs between the scenarios

In these models only two inputs take different values in different scenarios: GDP per capita (the SSP, from 2027 on) and malaria suitability (the RCP; it varies by draw). Model 7427 adds wind speed (RCP, by draw). Everything else that feeds the counts is the same in all three scenarios.

  • Same in every scenario: population (the count denominator and the age/sex split), DAH per capita, vaccine coverage and the vaccine factor per admin-2.
  • Different by scenario but not a model term: minimum temperature (from 2024) and flood exposure (from 2015).
  • Each admin-2 is shifted so its 2023 value equals the GBD-raked observation, so only the change in each input since 2023 moves the forecast.
